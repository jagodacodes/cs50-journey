# Filter

## Objective

Implement image filters by modifying the pixels of a BMP image.

## Concepts Practised

- Pointers
- Arrays
- Memory
- Image processing
- Functions

## What This Program Does

The program applies different image filters, such as grayscale, sepia, reflection, and blur, by manipulating the RGB values of each pixel in a bitmap image.

## Files

- `helpers.c` – implementation of the image filters.
- `helpers.h` – function declarations.
- `filter.c` – provided driver program used to apply the selected filter.
- `Makefile` – build configuration.
- `images/` – sample input and output images.

## What I Learned

This exercise introduced me to low-level image processing and strengthened my understanding of arrays, pointers, and working directly with memory.
