# Volume

## Objective

Adjust the volume of a WAV audio file by multiplying every audio sample by a scaling factor.

## Concepts Practised

- Binary files
- File I/O
- Buffers
- Memory

## What This Program Does

The program reads an input WAV file, multiplies each audio sample by a user-provided factor, and writes the modified samples to a new output file while preserving the original file structure.

## Files

- `volume.c` – implementation of the audio volume adjustment.
- `volume.h` *(if included)* – header definitions.
- `Makefile` – build configuration.
- Sample audio files *(if included)* – input and output examples.

## What I Learned

This exercise strengthened my understanding of binary file manipulation and showed how multimedia files can be modified at the byte level.
