# Credit

## Objective

Write a program that determines whether a credit card number is valid and identifies its issuer.

## Concepts Practised

- Functions
- Loops
- Arithmetic operations
- Luhn's Algorithm

## What This Program Does

The program asks the user for a credit card number, validates it using Luhn's Algorithm, and determines whether it is an American Express, MasterCard, Visa, or an invalid card.

## What I Learned

This exercise taught me how to break a complex problem into smaller steps and implement a real-world validation algorithm.
