# Mario

## Objective

Write a program that prints a pyramid of hashes (`#`) based on the height entered by the user.

## Concepts Practised

- User input
- Loops
- Nested loops
- Input validation

## What This Program Does

The program asks the user to enter the height of a pyramid and then prints a properly aligned pyramid using nested loops.

## What I Learned

This exercise helped me understand how nested loops work and how to translate a visual pattern into code.
