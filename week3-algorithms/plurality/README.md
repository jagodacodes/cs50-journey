# Plurality

## Objective

Implement a plurality voting system that determines the winner of an election based on the highest number of votes.

## Concepts Practised

- Arrays
- Structures (`struct`)
- Functions
- Command-line arguments
- Loops

## What This Program Does

The program accepts a list of candidates as command-line arguments, records votes entered by users, and determines the winner based on the largest number of votes received.


## What I Learned

This exercise introduced me to structures in C and helped me understand how to organise related data and process user input efficiently.
