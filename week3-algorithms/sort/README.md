# Sort

## Objective

Analyse and compare the performance of different sorting algorithms on datasets of various sizes and levels of ordering.

## Concepts Practised

- Algorithm analysis
- Time complexity
- Sorting algorithms
- Performance comparison

## What This Project Does

This assignment focuses on analysing how different sorting algorithms perform under various input conditions rather than implementing the algorithms themselves.

## Files

- `answers.txt` – answers to the theoretical questions about sorting algorithms.
- `random5000.txt`, `random10000.txt`, `random50000.txt` – randomly ordered datasets.
- `reversed5000.txt`, `reversed10000.txt`, `reversed50000.txt` – datasets sorted in reverse order.
- `sorted5000.txt`, `sorted10000.txt`, `sorted50000.txt` – already sorted datasets used for performance analysis.

## What I Learned

This exercise helped me understand how input data affects algorithm performance and strengthened my understanding of computational complexity and Big O notation.
