# Substitution

## Objective

Implement a substitution cipher using a 26-letter encryption key provided by the user.

## Concepts Practised

- Strings
- Arrays
- Command-line arguments
- Input validation

## What This Program Does

The program encrypts plaintext by replacing each letter with its corresponding letter from a user-defined substitution key while preserving case.

## What I Learned

This exercise strengthened my understanding of string manipulation, input validation, and mapping one set of characters to another.
