# Scrabble

## Objective

Create a program that calculates and compares the Scrabble scores of two words.

## Concepts Practised

- Arrays
- Loops
- Functions
- Character processing

## What This Program Does

The program assigns point values to each letter, calculates the total score for two words, and determines the winner based on the higher score.

## What I Learned

This exercise helped me practise working with arrays and reinforced the importance of breaking a problem into reusable functions.
