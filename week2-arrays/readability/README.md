# Readability

## Objective

Write a program that estimates the reading level of a text using the Coleman-Liau index.

## Concepts Practised

- Strings
- Arrays
- Loops
- Character analysis

## What This Program Does

The program analyses a piece of text by counting letters, words, and sentences, then calculates its readability grade using the Coleman-Liau formula.

## What I Learned

This exercise helped me understand how to process text in C and perform calculations based on string data.
